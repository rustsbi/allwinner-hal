# Nezha D1-H examples

## UART example

```bash
cargo run -p d1-allwinner-nezha --bin uart --target riscv64imac-unknown-none-elf --release
```

## Blinky example

```bash
cargo run -p d1-allwinner-nezha --bin blinky --target riscv64imac-unknown-none-elf --release
```

## SD/MMC example

```bash
cargo run -p d1-allwinner-nezha --bin sdmmc --target riscv64imac-unknown-none-elf --release
```
